# product.md — «ФінКіт», Спринт 1
**Продукт:** П2 «ФінКіт» (slug finkit) · **Команда:** Finkitiky · **Дата:** 18.09.2026 · **Автори:** Сизова Марія (КТ)

## 1. Профіль компанії і продукту
«ФінКіт» — фінтех-компанія з Дніпра (заснована 2021 року), що розробляє і супроводжує онлайн-банкінг для невеликого регіонального банку приблизно на 40 тисяч клієнтів — фізичних осіб. Продукт — вебзастосунок: серверна частина на Java (Spring Boot), інтерфейс на React, СУБД PostgreSQL, інтеграція з процесинговим центром банку через захищений API. Команда розробки — 14 осіб. Відділ забезпечення якості створено після інциденту з подвійним списанням коштів при переказі, тому регулятор вимагає документованого тестування перед кожним релізом — «досьє якості» є частиною процесу випуску. Стратегічний напрям компанії — розвиток онлайн-кредитування без відвідування відділення банку.

## 2. Користувачі та ролі

| Роль | Що робить у продукті | Приклад |

| **Ризик-менеджер** | Розглядає заявки, що не пройшли автоматичний скоринг, встановлює ліміти | Сергій ухвалює рішення щодо заявки на 400 000 грн |

## 3. Бізнес-процеси

### 3.1 Переказ коштів
* **Учасники (пули/доріжки):** Клієнт; Банк (система, операціоніст); Процесинговий центр.
* **Тригер:** клієнт надіслав форму переказу. 
* **Кроки:** 1) клієнт вводить суму і рахунки → 2) система перевіряє формат реквізитів → 3) перевіряє баланс і денний ліміт → 4) при перевищенні ліміту — підтвердження операціоністом → 5) списання і зарахування однією транзакцією → 6) запис обох операцій в історію → 7) результат клієнту. 
* **Кінцеві події:** «Виконано» / «Відхилено системою» / «Відхилено операціоністом». 
* **Розгалуження:** XOR (реквізити), XOR (ліміт), AND (списання і зарахування паралельно), повідомлення до процесингового центру.

### 3.2 Оформлення кредиту
* **Учасники:** Клієнт; Банк (скоринг, ризик-менеджер, операціоніст). 
* **Тригер:** клієнт подав заявку. 
* **Кроки:** 1) клієнт вказує суму, перший внесок і рахунок → 2) система перевіряє межі суми і строку → 3) автоматичний скоринг → 4) за граничної оцінки або великої суми — ручний розгляд ризик-менеджером → 5) рішення повідомляється клієнту → 6) клієнт підтверджує умови → 7) зарахування коштів і створення графіка платежів. 
* **Кінцеві події:** «Кредит видано» / «Відмовлено автоматично» / «Відмовлено ризик-менеджером» / «Не підтверджено». 
* **Розгалуження:** XOR за даними на три гілки (результат скорингу), таймер (підтвердження не надійшло за 7 днів).

### 3.3 Відкриття рахунку
* **Учасники:** Клієнт; Банк (система, операціоніст). 
* **Тригер:** клієнт обрав «відкрити рахунок».
* **Кроки:** 1) клієнт обирає тип рахунку (поточний/ощадний) і рахунок для початкового внеску → 2) система перевіряє, чи клієнт ідентифікований → 3) для нового клієнта операціоніст перевіряє документи → 4) система перевіряє достатність коштів → 5) створює рахунок і переносить внесок → 6) показує номер рахунку і надсилає повідомлення. 
* **Кінцеві події:** «Рахунок відкрито» / «Відмовлено (документи)» / «Недостатньо коштів». 
* **Розгалуження:** XOR (ідентифікований чи ні), XOR (достатньо коштів).

## 4. Замовлення на нову функцію та очікування замовника
**Замовлення від керівництва «ФінКіт»:** клієнти хочуть знати умови кредиту до візиту у відділення. Потрібен кредитний калькулятор із заявкою онлайн: клієнт сам рахує платіж, бачить графік і одразу отримує попереднє рішення. Ліміти й формули мають повністю збігатися з тими, за якими працює банк — жодних приблизних цифр.

**Очікування замовника (основа для user stories Лізи, US-01…):**
1. Клієнт вводить суму, строк у місяцях і ставку та бачить щомісячний ануїтетний платіж і загальну переплату.
2. Калькулятор показує графік за місяцями: дата, тіло кредиту, відсотки, залишок.
3. Система не приймає суму/строк/ставку поза лімітами банку і пояснює причину.
4. Клієнт подає заявку одразу з калькулятора і за кілька секунд бачить попереднє рішення.
5. Ризик-менеджер бачить заявки на ручний розгляд разом із результатом скорингу.
6. Клієнт бачить статус заявки у кабінеті й отримує повідомлення про його зміну.
