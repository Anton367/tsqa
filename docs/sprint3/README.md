## 4. Посилання на трекер та артефакти
Підтверджені звіти про дефекти знаходяться у файлі `bug-reports.md`. Докази завантажено у папку `attachments/`. Також додано `retro.md` з результатами зустрічі.

## 5. Висновки (Definition of Done)
1. Норматив тест-кейсів виконано (20 із 20), кейси незалежні.
2. Журнал виконання містить достовірні дані. Усі проблеми з блокуванням кейсів успішно вирішені після уточнення вимог.
3. **УВАГА: Норматив звітів про дефекти (8) наразі не виконано.** Інженер з тестування підтвердила лише 3 дефекти. Команді необхідно знайти ще 5 реальних багів для допуску до здачі.
4. Рецензування кейсів виконано 100%. Рецензування багів очікує поповнення реєстру.
