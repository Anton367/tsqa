
## Уточнення вимог бізнес-логіки

Відповідальна: Ліза (КТ)
Рецензент: Антон (ТА)

### BL-40 — денний ліміт переказів

SRS 1.1: 100 000 грн на добу, статус [ПІДТВ.].
Модуль v1: DAILY_LIMIT = 50000.

Питання: який ліміт потрібно використовувати
під час тестування — 50 000 чи 100 000 грн?

Статус: очікує підтвердження.
Рішення: ще не отримано.

### BL-50 / BL-60 — IBAN

SRS 1.1 вимагає перевірки формату IBAN
та контрольних цифр за алгоритмом MOD-97.

У TransferValidator v1 реалізована перевірка
формату, але немає MOD-97.

Питання: чи підтверджується вимога BL-60
для поточної версії модуля і як оформити
відсутність її реалізації?

Статус: потребує уточнення.
Рішення: ще не отримано.
